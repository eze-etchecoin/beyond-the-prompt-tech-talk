# Presentación

Aquí se almacena la presentación **PowerPoint** de la charla y cualquier versión
exportada (por ejemplo, a **PDF**).

## Contenido actual

- `presentation.pptx` — presentación de la charla
  (ya disponible dentro del directorio de trabajo al inicializar el repositorio).

## Notas

- Este directorio es el lugar canónico para los archivos de la presentación.
- No se genera una presentación nueva desde el repositorio: se versiona la que ya
  existe y sus exportaciones.
- Al exportar a PDF, guardá el archivo aquí junto al `.pptx` de origen.
