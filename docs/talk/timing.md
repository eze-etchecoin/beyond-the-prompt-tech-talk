# Timing de la charla

> Duraciones **provisionales**, calculadas sobre una charla de **60 minutos**.
> Se ajustarán a medida que se ensayen las demos.

| Bloque                              | Duración | Acumulado |
| ----------------------------------- | -------- | --------- |
| Introducción                        | 5 min    | 5 min     |
| Prompt Engineering                  | 8 min    | 13 min    |
| Context Engineering                 | 7 min    | 20 min    |
| Harness Engineering                 | 10 min   | 30 min    |
| Loop Engineering                    | 12 min   | 42 min    |
| Graph Engineering                   | 13 min   | 55 min    |
| Conclusión y preguntas              | 5 min    | 60 min    |

**Total:** 60 minutos.

Notas:
- Los bloques de Loop y Graph son los más largos porque concentran las ideas
  más novedosas; si el tiempo aprieta, son los primeros candidatos a recortar.
- Reservar margen para preguntas intermedias dentro de cada demo.
